# Lista de imagens do site

Coloque cada imagem na pasta indicada, com **exatamente** o nome abaixo (em minúsculas).
Formatos aceitos: .jpg, .jpeg, .png, .webp ou .avif. Enquanto uma imagem não existir, o site mostra um espaço colorido no lugar.

Todas as pastas ficam dentro de `src/assets/imagens/`.
